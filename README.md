# Алгоритми та структури даних — лабораторні роботи

**Студент:** Котяш Андрій
**Група:** ІПЗ-3/1
**Мова програмування:** C# (.NET 8)

## Як запустити

Потрібен [.NET SDK 8.0](https://dotnet.microsoft.com/download/dotnet/8.0). Команди виконуються з кореня репозиторію.

### Лабораторна 3. Масив і список (`lab03`)

| Задача | Що робить | Запуск |
|---|---|---|
| 1. Журнал у зворотному порядку | Збирає рядки додаванням у кінець списку, потім один раз розвертає | `dotnet run --project lab03/task1-reverse-log` |
| 2. Підсумки за місяцями | Масив на 12 елементів, номер місяця — індекс | `dotnet run --project lab03/task2-monthly-totals` |
| 3. Останні N подій | Кільцевий буфер на 5 комірок без зсуву елементів | `dotnet run --project lab03/task3-last-events` |

### Лабораторна 4. Пошук у даних (`lab04`)

Лінійний і бінарний пошук із лічильником порівнянь, вісім тестових випадків і експеримент з невідсортованими даними.

```bash
dotnet run --project lab04
```

### Лабораторна 5. Сортування об'єктів (`lab05`)

Сортування списку студентів за прізвищем, за балом і за групою з балом; перевірка стабільності сортування.

```bash
dotnet run --project lab05
```
